# Project notes

- This repository is built around operational flow and waiting time, not product sales, customer lifetime value, marketing response, or forecasted stock needs.
- The complete dataset and event log are generated with a fixed random seed in `src/build_project.py`.
- The dashboard is generated by `src/make_dashboard.py`, which embeds the request data in the HTML so a local web server is not required.
- Charts are drawn using Chart.js from a CDN. A live internet connection is needed for those plots.
- All SLA targets and customer ratings are illustrative.
- The report's PDF and images in `visualizations/` are outputs, not source data.
- `outputs/operations_analytics.db` contains `service_requests` and `request_activity_log` tables.
